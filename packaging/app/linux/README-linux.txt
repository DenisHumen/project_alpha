Kinolune for Linux (x86_64)
===========================

Requirements: GTK 3 and the system libmpv (media playback goes through it).
  Ubuntu/Debian:  sudo apt install libmpv2 libgtk-3-0
  Fedora:         sudo dnf install mpv-libs gtk3
  Arch:           sudo pacman -S mpv gtk3

Run the executable in this directory (for example ./kinolune).

Licences: LICENSE (MPL-2.0) covers Kinolune itself; THIRD-PARTY-NOTICES.md and
licenses/ cover third-party code (licenses/FLUTTER-NOTICES.txt lists the
Flutter engine and every Dart package). libmpv and FFmpeg are not shipped in
this archive: the system copies are used.
