# DSN-ADR-0001. Инструмент дизайна и источник правды

- **Статус:** предложено (proposed) — финальный выбор инструмента за владельцем.
- **Дата:** 2026-11-13
- **Задача:** DSN-001 (`docs/ROADMAP.md`)
- **Ссылки:** `docs/research/01-product-ux-design.md` §4.4, §4.8, §5.1–5.2; `docs/STRATEGY.md` v2.

> ADR лежит в `design/decisions/`, потому что `docs/adr/` принадлежит workstream DOC, а нумерация основных ADR (0001–0007) зарезервирована задачей DOC-001. После мержа DOC-001 этот документ можно перенести в `docs/adr/` со следующим свободным номером (отдельным PR).

## Контекст

- Проект — open source (MPL-2.0), без бюджета на подписки; контрибьюторы приходят со стороны и должны иметь возможность открыть и поправить макеты **бесплатно**.
- Исследование 01 §5.1 рекомендовало Figma Professional, но писалось для коммерческой модели с бюджетом. STRATEGY v2 эту модель отменила; ROADMAP (DSN-001) прямо рекомендует Penpot.
- Одна дизайн-система на четыре плотности (TV, desktop, tablet, phone) и много платформ: токены должны генерироваться в код (DSN-003, Style Dictionary), поэтому источник правды обязан жить в git и проходить ревью в PR.

## Варианты

| Критерий | Penpot | Figma Starter (бесплатно) | Figma Professional |
|---|---|---|---|
| Цена для контрибьютора | 0 (облако penpot.app или self-host) | 0, но ограничения на файлы в командах | ~$16/мес за Full seat **[проверить на figma.com]** |
| Лицензия | MPL-2.0, open source | Проприетарный SaaS | Проприетарный SaaS |
| Вендор-лок | Нет: self-host, открытый формат экспорта | Да | Да |
| Токены | Нативные design tokens (W3C-подобные); импорт/экспорт JSON **[проверить текущую совместимость с DTCG]** | Variables + плагин Tokens Studio | То же + Dev Mode |
| Лэйаут | Flex и CSS Grid — близко к коду | Auto Layout, Grid | Auto Layout, Grid |
| Прототипирование | Базовое | Сильное | Сильное |
| Готовые киты | Мало (Apple/Material — нет официальных) | Apple Design Resources, Material 3 | То же |
| Работа в Linux | Браузер, любой ОС | Браузер / десктоп-клиент | То же |

## Решение (рекомендация)

1. **Источник правды — файлы в git, а не файл макетов:**
   - токены — W3C DTCG JSON в `design/tokens/` (дальше DSN-002, DSN-003);
   - иконки — SVG в `design/icons/svg/` (DSN-004);
   - бренд, иллюстрации, плейсхолдеры, motion — мастер-файлы в своих каталогах `design/`.
   Любой инструмент дизайна — лишь редактор этих файлов. Изменение, которого нет в git, не существует.
2. **Основной инструмент макетов — Penpot** (рекомендация). Причины: бесплатен для всех контрибьюторов, open source с совместимой лицензией (MPL-2.0), self-host снимает зависимость от вендора, Flex/Grid ложатся на код, нативные токены.
   - Общий командный проект — в облаке penpot.app (бесплатно) под организацией проекта; ссылки на файлы — в `design/sources/README.md`.
   - Экспорт `.penpot` мастер-файлов периодически кладётся в `design/sources/` (Git LFS), чтобы макеты переживали потерю аккаунта или сервиса.
3. **Figma допускается как личный инструмент** контрибьютора (бесплатный Starter), но вклад принимается только в виде файлов в git (токены JSON, SVG, PNG-экспорт, ссылка на публичный файл для просмотра). Платные seat'ы проект не покупает.
4. **Вспомогательные инструменты** (все бесплатны): Excalidraw — user flows; Inkscape — SVG; Blender / Krita — иллюстрации; Rive (бесплатный план) или Lottie — motion; Apple Icon Composer и `layerutil` — только для генерации Apple-ассетов из мастер-файлов (DSN-006).

## Последствия

- **Плюсы:** нулевой порог входа для дизайнеров-волонтёров; нет вендор-лока; ревью дизайна идёт через PR как ревью кода; CI может проверять токены, контраст и SVG.
- **Минусы:** нет готовых Apple/Material-китов в Penpot — компоненты рисуем сами (это и так нужно для собственной идентичности, 01 §4.1 п.5); прототипирование фокус-навигации TV слабое — проверяем на реальном TV-клиенте (TV-*), а не в прототипе.
- **Риски:** формат токенов Penpot может отличаться от DTCG — тогда синхронизация через скрипт-конвертер в `tools/` или ручной перенос; git-JSON остаётся главным.
