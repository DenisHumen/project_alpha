# DSN-ADR-0002. Набор иконок и шрифт

- **Статус:** принято мейнтейнером (ADR-0011 делегирует дизайн-решения); владелец может пересмотреть.
- **Дата:** 2026-11-13
- **Задачи:** DSN-004, DSN-005 (`docs/ROADMAP.md`)
- **Ссылки:** `docs/research/01-product-ux-design.md` §4.4, §4.8, §5.2; `design/LICENSES.md`.

## Иконки: Lucide (ISC), а не Phosphor (MIT)

| Критерий | Lucide | Phosphor |
|---|---|---|
| Лицензия | ISC — совместима с MPL-2.0, только сохранить уведомление | MIT — то же |
| Геометрия | Нативно 24×24, штрих 2 px, скруглённые концы и стыки — ровно наш стиль (01 §4.8: 1.75–2 px на 24 px) | Сетка 256×256, штрих 16 (≈ 1.5 px на 24); для 1.75–2 px нужен вес *bold* или пересчёт |
| Перекрашивание | `stroke="currentColor"`, без заливок — тонируется одной операцией везде (Flutter `ColorFilter`, SwiftUI template) | Веса *fill*/*duotone* содержат заливки; тоже можно, но набор неоднороден |
| Охват для медиаплеера | play/pause/skip/rewind, captions, audio-lines, picture-in-picture, cast, repeat-1, list-music, mic-vocal, tv, server, network — всё есть | Тоже есть |
| Поставка | npm `lucide-static` — плоские SVG, версия закрепляется в `package-lock.json` | npm `@phosphor-icons/core` |

Решение: **Lucide**, штрих уменьшен до **1.75 px** — чуть легче и ближе к HIG-эстетике на крупных TV-размерах. Курированный набор — 92 иконки в `icons/manifest.json` (MVP требовал 60). Имена — по смыслу (`seek-back`), а не по форме Lucide (`rotate-ccw`), чтобы замена рисунка не меняла код. Один набор на всех платформах, включая Apple (01 §4.8); системные контролы (AirPlay-пикер, share sheet) остаются нативными.

## Шрифт: Inter Variable 4.1 (OFL-1.1)

Проверено на `InterVariable.ttf` 4.1 (fontTools):

- кириллица: полный русский алфавит с Ё/ё, а также украинские, белорусские, сербские/македонские и казахские буквы; 249 из 304 символов блоков Cyrillic + Supplement; `locl` для локальных форм;
- типографика: `«»`, `—`, `–`, `…`, `№`, `₽`, узкие пробелы;
- OpenType: `tnum` (табличные цифры для таймкодов и битрейтов), `case`, `zero`, `frac`, стилистические наборы;
- оси: `wght` 100–900, `opsz` 14–32 (крупные TV-заголовки получают оптический размер Display).

Запасные Manrope (OFL) и Golos не нужны: Inter закрывает кириллицу. Для Golos UI лицензия OFL не подтверждена (под OFL опубликован Golos Text) — его не берём.

На Apple-платформах — системный SF (лицензия SF разрешает только Apple-платформы); токены задают Inter, генератор для Swift (DSN-003) отображает его на системный шрифт.

## Бинарники не в git

Шрифты скачиваются скриптом `scripts/fonts-fetch.mjs` с проверкой SHA-256 (`fonts/fonts.lock.json`) — без Git LFS и без раздувания истории. Минус: сборке нужен один дополнительный шаг (и доступ к GitHub Releases или заранее скачанный архив).

## Последствия

- Новая иконка — строка в манифесте; CI проверяет стиль и свежесть сгенерированного кода.
- Обновление Inter — новая версия в `fonts.lock.json` с новыми хешами, проверка образца `fonts/specimen.html`.
