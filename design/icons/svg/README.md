# icons/svg

Исходные SVG иконок интерфейса (DSN-004).

- Сетка 24×24, `viewBox="0 0 24 24"`, штрих 1.75–2 px, скруглённые окончания, `stroke="currentColor"`, без заливок цветом и встроенных растров.
- Имя файла — `kebab-case.svg` (`play.svg`, `skip-forward.svg`); из имени генерируется `Icon.play` и т. п.
- Основа — Lucide (ISC) или Phosphor (MIT); выбранный набор и доработки отмечаются в `../../LICENSES.md`.
- Не класть: SF Symbols, иконки Infuse/Firecore, логотипы сервисов (те — в отдельной папке по DSN-007).
