# placeholders

Собственные плейсхолдеры для отсутствующего арта (DSN-006). Арт TMDB, Fanart.tv и других сервисов сюда **не кладём**: он показывается только у пользователя с атрибуцией по условиям API.

| Мастер (SVG) | PNG (`export/`) | Где |
|---|---|---|
| `poster.svg` | 400×600 | постер фильма/сериала 2:3 |
| `backdrop.svg` | 1280×720 | backdrop, кадр эпизода, карточка 16:9 |
| `album.svg` | 512×512 | обложка альбома 1:1 |
| `artist.svg` | 512×512 | фото артиста или актёра 1:1 (клиент обрезает кругом) |

Тёмный нейтральный фон из серой рампы токенов и приглушённый знак Kinolune (белый 10–14 %), поэтому поверх читаются белый текст и `scrim/*`. PNG генерирует `just design brand` (`scripts/brand-build.mjs`); руками не править. В клиентах можно брать SVG (векторно) или PNG.
