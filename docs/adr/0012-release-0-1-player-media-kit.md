# ADR-0012: media_kit как плеер релиза 0.1

- Статус: Принят
- Дата: 2026-11-13

## Контекст

Нужен наглядный релиз 0.1 для Linux и Android как можно скорее (ADR-0011). Нативные поверхности плеера (ADR-0003, ADR-0008, ADR-0009) дают HDR/DV/AFR, но требуют отдельной работы на каждой платформе.

## Решение

В релизе 0.1 плеер — пакет `pa_player` на **media_kit** (libmpv, LGPL, динамическая линковка) для Linux и Android. API `pa_player` (docs/dev/release-0.1-contract.md) не зависит от движка; в следующих релизах за ним появляются нативные движки (Media3 Activity на Android, libmpv-окно для HDR на десктопе) без изменения экранов приложения.

## Последствия

- 0.1 — только SDR-качество картинки гарантировано; HDR тон-маппится mpv.
- Проверка лицензий media_kit и его сборок libmpv — в PR R01-PLAYER (только LGPL-варианты).
