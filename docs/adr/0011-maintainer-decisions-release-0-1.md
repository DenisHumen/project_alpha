# ADR-0011: Решения мейнтейнера по открытым вопросам и приоритет релиза 0.1

- Статус: Принят
- Дата: 2026-11-13
- Закрывает: DEC-003, DEC-004 (рабочее), DEC-005 (на релиз 0.1), DEC-006, DEC-008; решения DSN-001 и META-001

## Контекст

Владелец проекта делегировал все технические и продуктовые решения мейнтейнеру (ведущему агенту): «с меня идея и направление, с вас реализация; главное — удобно для клиента». Также поставлена цель: **первый наглядный релиз как можно скорее**, NAS-дистрибутив — в последнюю очередь.

## Решения

1. **Приоритет — релиз 0.1** (новая веха R0.1, см. ROADMAP): Linux-десктоп и Android, источники «локальная папка» и SMB, распознавание и медиатека с постерами, плеер, «Продолжить просмотр», базовый музыкальный плеер. Сборка в CI, публикация в GitHub Releases. Дистрибутив (DIST-*) — после первого запуска клиентов.
2. **DEC-003 донаты в store-сборках:** в первых store-релизах донатов нет. Ссылки на донаты — только в full-сборках, README и на сайте.
3. **DEC-004 название:** рабочее имя продукта — **Kinolune**, NAS-ОС — **Kinolune OS** (кандидат №1 из docs/legal/naming.md). До ручной проверки товарных знаков (USPTO/TMview/WIPO) репозиторий и пакеты не переименовываем; в UI имя задаётся одной константой.
4. **DEC-005 кодеки (релиз 0.1):** клиенты используют только LGPL-сборку FFmpeg/libmpv и аппаратные декодеры платформы; патентно-обременённые энкодеры не поставляем. Вопрос серверного транскода — к вехе сервера.
5. **DEC-006 Twitch:** вход через Device Code Flow (по QR на ТВ), без логина — локальное избранное.
   - **store-сборки:** просмотр только через официальный встраиваемый плеер Twitch, без загрузок (требование Developer Agreement).
   - **full-сборки** (GitHub, F-Droid, Flathub, AUR, десктоп, сервер): нативное воспроизведение и загрузки VOD/эфиров по явному действию пользователя для личного использования, без зарегистрированного client_id проекта в этих запросах (как streamlink/yt-dlp); реклама не блокируется. Модуль отключаем удалённым флагом, если Twitch изменит API.
6. **DEC-008 ключ TMDB:** встроенный ключ проекта (бесплатное некоммерческое использование с атрибуцией) + поле «свой ключ». Ключ проекта создаёт владелец; до его появления приложение просит ключ пользователя и работает без постеров по распознанным названиям.
7. **Инструмент дизайна (DSN-001):** Penpot (облако penpot.app); источник истины — файлы в git. Исходники макетов в репозиторий не кладём, только ссылки и экспорт.
8. **Корпус распознавания (META-001):** пока в этом репозитории, только собственные данные проекта. Отдельный репозиторий — когда появятся данные с несовместимыми лицензиями.
9. **Резервный вариант метаданных (идея владельца, на будущее):** если прямые запросы к провайдерам станут ненадёжными — публичное зеркало основных метаданных (фильмы, сериалы, аниме, музыка), обновляемое раз в сутки, при условии объёма не в терабайты и совместимых лицензий (CC0 MusicBrainz, ODbL anime-offline-database, IMDb non-commercial datasets и т. п.). Сейчас не делаем; оценку объёма и лицензий — отдельной задачей.

## Последствия

- ROADMAP: DEC-003, DEC-006, DEC-008 закрыты; DEC-004 закрыт с рабочим именем; новая веха R0.1 со своими задачами.
- Задачи TWI-* следуют разделению store/full из п. 5 и ADR-0007.
- Требуется от владельца: аккаунт TMDB для ключа проекта (DEC-007 — аккаунты Apple/Google — к store-релизам).
