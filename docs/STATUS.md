## Как продолжить с другого ПК

1. `git clone https://github.com/DenisHumen/project_alpha && cd project_alpha`
2. Прочитать `CLAUDE.md`, этот файл, `docs/adr/0011-*`.
3. Посмотреть открытые PR: `gh pr list`. Готовые с зелёным CI — слить (squash), остальные — доделать.
4. Следующие задачи: те, у которых все `deps` отмечены в ROADMAP (после REPO-012 — `just roadmap next`).
5. Правила: одна задача — одна ветка `feat/<ID>-slug`, `git commit -s`, PR с `[<ID>]`, галочка в ROADMAP в том же PR.
