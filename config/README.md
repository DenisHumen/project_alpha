# config/ — удалённый конфиг приложения

Статические файлы, которые приложение Kinolune скачивает напрямую из этого репозитория (raw.githubusercontent.com, позже GitHub Pages). Своих серверов у проекта нет (ADR-0004); клиент — крейт [`pa-remote-config`](../core/crates/pa-remote-config) (CORE-014).

| Файл | Что это |
|---|---|
| `remote-config.json` | Флаги, kill-switch'и, политика обновления, значения для Twitch (TWI-004). **Сейчас — пример без подписи**: приложение его отвергает и работает на встроенной копии. |
| `remote-config.json.minisig` | Подпись minisign. Появится, когда владелец создаст ключ и подпишет файл. |

Правила:

- Файл без верной подписи приложение не принимает; подпись делает только владелец, офлайн, своим ключом — см. [docs/dev/remote-config.md](../docs/dev/remote-config.md).
- Каждая новая публикация увеличивает `serial`: документ с меньшим `serial`, чем у приложения, отвергается.
- Никаких секретов и персональных данных: файлы публичны.
