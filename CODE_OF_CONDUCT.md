# Кодекс поведения / Code of Conduct

Проект следует [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) (русский перевод: https://www.contributor-covenant.org/ru/version/2/1/code_of_conduct/).

Коротко: уважайте других участников, без оскорблений, травли и дискриминации; критикуйте код, а не людей.

О нарушениях сообщайте мейнтейнерам через приватный отчёт GitHub (вкладка **Security → Report a vulnerability** не подходит — используйте личные сообщения мейнтейнеру или issue с пометкой `conduct`, если это не требует приватности). Мейнтейнеры вправе удалять комментарии, коммиты и блокировать участников, нарушающих кодекс.
