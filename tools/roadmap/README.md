# Инструменты ROADMAP (REPO-012)

`roadmap.py` проверяет [`docs/ROADMAP.md`](../../docs/ROADMAP.md) и выдаёт задачи, которые можно брать.
Только стандартная библиотека Python ≥ 3.10, без зависимостей.

| Команда | Что делает |
|---|---|
| `just roadmap lint` | Проверка файла; код возврата 1 при ошибках. Входит в Definition of Done (§0.3) и в CI |
| `just roadmap next` | Открытые задачи, у которых все `deps` отмечены `[x]` и нет открытого PR с `[ID]` в заголовке |
| `just roadmap next CORE PLAY-AND` | То же, только для указанных workstream |
| `just roadmap next --offline` | Без запроса к GitHub (`gh` не нужен) |
| `just roadmap next --json` | Машиночитаемый список для запуска волн агентов |
| `just roadmap test` | Unit-тесты инструмента |

## Что проверяет `lint`

Ошибки (lint красный):

- строка задачи имеет вид `- [ ] **ID** Название` (или `- [x]`, или зачёркнутая отменённая задача); ID уникальны;
- ID стоит в разделе своего workstream (`### 3.N. CORE — …`);
- у каждой неотменённой задачи есть строки `Что:`, `deps:` и `done when:`; строка `deps:` имеет формат
  `deps: … · size: S|M|L · parallel: yes|no · веха: MN · ref: …`;
- все ID в `deps` и в пометке `(blocked: …)` существуют, не указывают на саму задачу и на отменённые задачи;
- в графе зависимостей нет циклов;
- у задачи `[x]` все зависимости тоже `[x]` (для задач `(owner)` — только предупреждение: владелец
  может принять решение раньше, чем закрыто исследование, которого оно ждало);
- задача не зависит от задачи более поздней вехи.

Предупреждения (lint зелёный): повтор одинаковой строки поля и расхождение таблицы
«Сводка по количеству задач» с фактическим числом задач.

Блоки кода (```` ``` ````) игнорируются, поэтому пример формата в §0.1 не считается задачей.

## Как `next` выбирает задачи

Задача попадает в список, если она открыта, не отменена, не помечена `(owner)`, все её `deps`
и блокеры из `(blocked: …)` отмечены `[x]`, и среди заголовков открытых PR нет `[ID]`
(запрос `gh pr list --state open`). Если `gh` нет или он не авторизован, выводится
предупреждение, и фильтр по PR не применяется.
