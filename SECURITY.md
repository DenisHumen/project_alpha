# Безопасность / Security Policy

Пожалуйста, **не публикуйте уязвимости в открытых issue**.

Сообщайте приватно через GitHub: вкладка **Security → Report a vulnerability** в этом репозитории. Мы ответим в течение 7 дней и согласуем сроки раскрытия.

Please report vulnerabilities privately via **Security → Report a vulnerability**. Do not open public issues for security problems.

Поддерживаемые версии: до выхода 1.0 исправления выпускаются только для последней версии.
